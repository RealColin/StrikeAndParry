# Strike and Parry

Strike and Parry is a Minecraft combat overhaul for NeoForge
that introduces fluid attack animations and more dynamic,
skill-based melee combat.

## Features

- [ ] 🚧 **Fluid Attack Animations** - Smooth animations that flow with the pace of combat.
- [ ] 🚧 **Attack Combos** - Chain together different attacks based on the weapon you're wielding.
- [ ] **Parrying** - Deflect incoming attacks with well-timed defensive maneuvers.
- [ ] **Ripostes** - Punish opponents with swift counterattacks. 
- [ ] **Feinting** - Cancel or delay attacks to bait opponents into reacting.
- [ ] **Dual Wielding** - Fight with a weapon in each hand.
- [ ] **Two-Handed Combat** - Wield powerful two-handed weapons.
- [ ] **Improved Mob Combat** - Mobs use the same combat mechanics as players. 

## Development Status
Strike and Parry is currently in active development.
